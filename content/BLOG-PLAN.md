# Blog plan

One new post every 3 to 6 days, and never more than one post on the same day. Publish the drafts first, then work down the queue. That's 38 posts, about 5 months.
Topics alternate: a bigger guide (brings clients) then a short one that answers a single question (for Google and AI assistants). Every post is published as a normal guide in the one Guides list; there is no separate "quick answers" section.

Topics are chosen by judgement, not search data. Check them in Google Keyword Planner and Search Console, and move the ones with real demand up.

## For each post

- Add a Markdown file to `content/guides/`. The file name becomes the URL.
- Start with a bold **short answer**, and end with a `## Questions` section (this becomes FAQ markup).
- Write for clients anywhere in the world, not only India, and not for other designers.
- Use real projects only. Never invent results or numbers.
- Don't promise rankings or leads.
- Add the link to `public/llms.txt`.

## Drafts ready to publish

These are finished and waiting in `content/drafts/`, which the site doesn't read. To publish one, move it to `content/guides/`, set `date` to that day, and add its link with the other guides in `public/llms.txt`.
